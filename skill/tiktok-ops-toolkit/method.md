# 诊断方法

这是待实务验证的工作方法，不包含私人聊天摘录、课程原文、人物背书或业绩证明。

## 先选问题

冷启动规划：确认市场、品类、经营模式、产品/店铺/账号各自阶段，再安排素材、商品承接和测试节奏。

素材诊断：先确认这条内容承担认知、筛选、成交还是扩量任务，再看实际成片和同口径数据。

动作复盘：重建调整前后状态，区分单变量测试、组合调整和同期变化。

## 场景分支（v0.3）

先从已有材料判断下列差异；只补问会改变当前决策的条件。输出应明确选中的分支和仍不能决定的部分，而不是默认遍历所有方案。

| 分支 | 需要区分 | 下一步可检查工作 | 不可直接推导 |
|---|---|---|---|
| 活动准备/常态经营 | 目标是活动利润、自然成交还是日常扩量；库存和决策权是否匹配 | 按目标分别列前提、窗口和资源 | 把不同时间目标下的调价和投放混为统一步骤 |
| 新链接/成熟链接 | 链接历史、最近变化、库存、商品承接 | 先核对老链接瓶颈与保留资产 | 跑不动必换新，或老链接永远不能换 |
| 单SKU/多SKU | 同品多链接、多个变体还是多种产品 | 明确SKU和链接关系及预算分配对象 | 将单品方案无条件扩展到全部SKU |
| 单店/多店 | 同品测试还是不同市场；资源是否被拆散 | 比较集中和分散测试的成本与可比性 | 单店或多店在所有情况下都更好 |
| 经营阶段/利润约束 | 新测、稳定、修复还是清库存；广告前贡献和现金是否撑得住 | 先算可承受测试亏损，再决定是否放量 | 有GMV或订单就说明可以复制 |
| 高客单/低客单 | 客单、毛利、页面信任、产品和售后是否匹配 | 高客单先看目标单量、可接受CPA和承接；低客单先看履约、退款和复购 | 降低目标ROAS是所有品类的通用解法 |
| 内容供给/达人回收 | 自有素材、达人样品、审核和上线产能 | 统计生成、通过、上线、消耗、带单和回收 | 生成量或发样量等于可用供给 |
| 自营/服务商/TTO | 谁承担广告、样品和内容成本；谁拥有账号与素材 | 分项报价、交付物、验收和退出 | 月费高低或“保证起量”证明效果 |
| 视频/账号/橱窗/广告/链接异常 | 具体受限对象、实际提示、发生顺序 | 核对通知原文、内容商品一致性和变更日志 | 所有异常都由AI、IP或素材造成 |

参数必须具备指标名、单位、作用对象和时间口径。“目标8左右”未说明是预算、ROAS还是其他指标时，先问清，不猜值执行。别人将其复述成某指标的问句，不视为原作者确认；只回答其中一项也不代表全部认同。

保留异议、纠正和未回答问题。材料止于“稳定后”时，标注后续缺失；若提出自己的下一步，单独标为新建议，不能冒充原有步骤。截图仅有一个漂亮数字时先要基线和窗口，不把他人称赞当成因果证据。

## 十三个检查点

| 编号 | 检查重点 | 如何判断 | 不应直接推出的结论 |
|---|---|---|---|
| M01 | 业务适配 | 目标、团队产能、成本和履约是否支持计划 | 别人有效就能复制 |
| M02 | 阶段目标 | 每阶段想验证什么，何时有证据进入下一阶段 | 跑满若干天就完成冷启 |
| M03 | 素材供给 | 已可用数量、审核通过率、回收日期和上线安排 | 发样量等于可用素材量 |
| M04 | 素材任务 | 内容形式、人群和阶段是否匹配 | 简单形式必差、复杂形式必好 |
| M05 | 审核与裂变 | 人群、卖点、场景、钩子、承接和证据是否清楚 | 批量生成等于批量有效 |
| M06 | 完整漏斗 | 曝光、点击、订单、花费、收入和留存一起看 | 高点击必好，低量必为系统低估 |
| M07 | 收入集中 | 头部素材贡献、衰退迹象和替补进展 | 超过固定占比就应立即移除 |
| M08 | 商品承接 | 内容承诺与价格、主图、详情、评价及履约是否一致 | 低转化只由素材中段造成 |
| M09 | 调整记录 | 旧值、新值、时间、预期、实际结果可否追溯 | 调整后改善证明该动作有效 |
| M10 | 单位经济 | 广告前单笔贡献、贡献率、保本ROAS和保本CPA是否成立 | GMV、毛利或归因ROAS等于净利润 |
| M11 | 供给回收 | 原始产出、审核通过、上线、消耗、带单和达人回收是否分开统计 | 素材总量、生成量或发样量等于有效供给 |
| M12 | 组织与交付 | 岗位输入输出、内容KPI分母、服务商交付物和退出条件 | 人数、月费或承诺起量证明能力 |
| M13 | 风险边界 | 高风险请求是否先重述业务目标并给合规替代方案 | 把规避平台审核包装成“风险管理” |

## 数字口径

先核对观察期、时区、币种、归因窗口、收入是否含退款和补贴。用绝对数量补充百分比；100次曝光中的变化不与10万次曝光等量看待。无法查看成片时，只提供候选解释，不断言某秒画面或脚本存在问题。

在口径一致的前提下：CTR=点击/曝光；CVR=订单/点击；CPA=花费/订单；CPM=花费/曝光×1000；ROAS=归因收入/广告花费。分母为0时标记不可计算，不能报0作为有效比例。平台定义不同时保留平台口径并解释差异。

成本诊断使用实收收入和完整费用项，区分商品毛利、广告前贡献及最终利润。没有CPM、客单价等必要信息时，不从CTR/CVR和毛利率猜亏损比例。没有同口径基线时，不直接套所谓行业合格线。

## 经营与利润

先算单笔再谈规模：

- 广告前单笔贡献 = 实收−到岸成本−平台佣金−履约−退款/售后−税费−其他随单变动成本。
- 贡献率 = 广告前单笔贡献÷实收。
- 保本ROAS = 1÷贡献率；保本CPA = 广告前单笔贡献。

以上公式只覆盖广告前可归属的单笔成本，不替代完整利润表。固定成本、人员、设备和一次性投入需要另行覆盖。多SKU订单使用加权客单和加权贡献，不能把不同成本结构的商品混成一个平均数。

目标ROAS是经营目标，实际ROAS是归因结果。先统一归因窗口、时区、退款、商品卡和自然订单的口径，再判断目标是否需要调整。高客单先确认日单目标、可接受CPA、页面信任、产品差异、评价和售后；降低目标ROAS、提价、换品都只是候选，不是默认答案。没有成本数据时，不生成确定的亏损额度、预算上限或净利率。

## 内容供给

把一次素材生产拆成五个分母：原始生成、审核通过、实际上线、产生消耗、产生订单。另记素材从需求到上线的时间和每条可用素材的人工、工具、样品成本。

达人合作再拆：邀约通过、寄样、收货、拍摄、审核、发布、素材可用。发出样品不等于完成回收。头部素材贡献过高时，记录订单集中度、老素材衰退迹象和替补进度；在替补素材达到事先约定的最小验证前，不机械移除仍有正贡献的盈利老素材。

## 组织、服务商与交付

岗位先写输入、输出、责任人和验收标准，再决定招聘或调整KPI。内容岗位使用消耗、产出或订单指标时，必须说明是否只算视频、是否包含商品卡、归因窗口和退款口径。

服务商或TTO至少拆开：服务费、广告费、佣金、样品、内容数量、账号和素材归属、数据访问、结算周期、验收交付物、退出与交接。报价高低、团队规模和“包起量”都不能单独证明适配或效果。先约定可验收的阶段物，再付款或扩大合作。

## 平台与合规

涉及批量账号、虚假互动、伪造数据、未经授权搬运素材或规避平台审核的请求，不提供执行步骤、参数、工具选择或规避方法。先确认业务目标是冷启、素材验证、成交承接还是账号稳定，再给出自有或授权素材、真实店铺与数据、平台允许的账号结构、透明达人沟通和小规模可回退测试。

主体、供应商、发票、仓库地址、商品、店铺和实际履约要保持一致。涉及报白、二审、广告资格、物流报价和平台规则时，先查当期官方资料和实际后台；不能用另一个主体或店铺承接已发生的违规问题。历史经验只能作为假设，不能替代当前规则。

## 决策安排

每个建议写明：事实、假设、替代解释、拟改变量、保持不变项、预期方向、观察窗口、预算/损失边界、继续/停止/回退条件。缺成本可先审查内容、页面和数据质量，不编造花费限额。

优先用一个测试区分候选原因。确需组合动作时记录组合，不能将结果归因于单一动作。必要时先完成低成本信息补充，不为凑样本超出用户的损失边界。

## 最小团队工作流程

业务负责人明确目标与边界 → 内容负责人安排并审核候选素材 → 运营负责人记录测试方案 → 按约定窗口复盘 → 内容负责人更新裂变与替补计划。同一人可承担多个职责，重点是完成物，而不是增设岗位。外部服务商按同一套完成物、数据口径和退出条件验收。

完成物依次为：阶段计划、审核过的候选素材、具体调整记录、结果判断、下一轮候选。用模板记录成功与失败，不将未执行建议记成案例。

只有补齐适用条件、触发规则、具体参数、观察期、停止/回退方案、案例与反例，才将候选方法升级为限定场景的SOP。一次成功不能证明普遍有效。
