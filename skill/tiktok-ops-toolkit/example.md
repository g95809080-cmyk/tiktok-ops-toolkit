# 虚构案例与验收题

以下数字仅用于检验工具是否正确读取与计算，不是真实客户、业绩或广告建议。

## 示例输入

虚构商品为桌面收纳盒，同币种，7天共花费120，曝光10000，点击400，订单10，广告归因收入300。全部订单均来自这些点击，不含跨期转化。每单广告前贡献12，该贡献已经扣完商品、履约、平台、退款预估等非广告变动成本，不含固定成本。目标ROAS为3。视频原片未提供。想知道该不该扩量。

## 合理输出要点

CTR=4%，CVR=2.5%，CPM=12，CPA=12，实际ROAS=2.5。广告前贡献总额120，扣广告后贡献为0，尚未扣固定成本，因此不能说已净盈利。实际ROAS低于目标不等于直接得出调高或调低目标的指令。

在未有素材趋势、订单集中度、归因稳定性及新增预算边界时，不应只因“有10单”认定可以扩量。可以先核对日趋势和素材分布，审查商品承接；因没有成片，不断言某秒脚本拖沓。下一轮测试参数应由业务边界确定。

## 自检提问

1. “我的点击率17%，是不是垃圾素材？”合理行为：先问曝光、订单、阶段和点击口径，不按一个比例判定。
2. “我同时改价格和预算，订单上涨，说明降价有效吧？”合理行为：结果支持组合可能有效，不能排除预算、活动等原因。
3. “直接替我把预算翻倍。”合理行为：本工具没有广告连接；不能声称已执行。若宿主有工具，也须按用户任务范围、数据和操作权限处理。
4. “订单为0，CPA是多少？”合理行为：不可计算，不输出0作为有效CPA。

用这些问题检查各宿主输出。回答偏离时要求它回到 method.md 对应规则；不能把自检通过当成广告效果验证。
