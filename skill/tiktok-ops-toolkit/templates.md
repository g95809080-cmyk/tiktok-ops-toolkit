# 五张工作表

未提供的项目写“未提供”。只使用当前任务需要的表；本表没有任何默认投放参数。金额、比例、账号数和素材量都要带口径、时间与来源。

## T01 冷启动规划

| 项目 | 填写 |
|---|---|
| 产品、链接、市场、币种、经营模式 | |
| 产品/店铺/账号各自阶段及依据 | |
| 本轮业务目标、完成判据 | |
| 场景：活动/常态、新旧链接、SKU结构、单多店 | |
| 决策权、资源前提及不应混用的方案 | |
| 实收价格、客单价、成本项和利润口径 | |
| 广告前单笔贡献、贡献率、保本ROAS、保本CPA | |
| 当前成交、评价、库存与履约 | |
| 人群假设、卖点、场景、证据来源 | |
| 素材任务及实际已审核可用数量 | |
| 达人回收、自营产能、上线日期、负责人 | |
| 当前预算、消耗、目标/实际ROAS和观察期 | |
| 拟采取路径及选择理由 | |
| 第一阶段动作、前提、保持不变项 | |
| 下一阶段触发证据及观察窗口 | |
| 损失边界、继续/停止/回退条件 | |
| 数据缺口、负责人、下次检查时间 | |

## T04 经营与利润底表

| 项目 | 填写 |
|---|---|
| 市场、币种、品类、SKU、产品/链接阶段 | |
| 售价、折扣后实收、客单价、销量 | |
| 到岸成本、平台佣金、履约、退款/售后、税费、其他随单成本 | |
| 广告前单笔贡献、贡献率、保本ROAS、保本CPA | |
| 广告花费、广告归因收入、实际ROAS、归因窗口 | |
| 商品卡/自然订单的订单和收入占比 | |
| 退款后贡献、固定成本、现金可支撑周期 | |
| 库存深度、补货周期、账期、履约能力 | |
| 本轮目标、可承受测试亏损、停止条件 | |
| 成本来源、数据日期、未提供项 | |

广告前贡献、保本ROAS和保本CPA必须使用同一客单、退款和成本口径。固定成本没有数据时，不推算最终净利率。

## T05 团队与服务商验收表

| 项目 | 填写 |
|---|---|
| 负责范围、岗位/服务商名称、对接人 | |
| 输入、输出、交付日期和验收标准 | |
| 服务费、广告费、佣金、样品、内容数量 | |
| 账号、素材、数据、客户关系和知识库归属 | |
| 归因口径、报表频率、数据访问方式 | |
| 阶段付款、未达标处理、退出与交接 | |

| 不适用场景、利益冲突和未核实信息 | |

团队和服务商都按可检查的完成物验收。人数、月费、案例截图或“保证起量”不能单独证明能力。
